# Spendi — Expense Tracker
Spendi is an Android expense-tracking application built with **Java** and **Room**. The project explores Android development and local data persistence to support personal expense management.

## Overview
Spendi is a personal project focused on building an Android application using Java and a local database. It provides an opportunity to apply object-oriented programming principles and Android development concepts in a practical project.

## Tech Stack
* **Language:** Java
* **Platform:** Android
* **Database:** Room Persistence Library
* **Build System:** Gradle

## Getting Started

### Prerequisites
* Android Studio
* Android SDK compatible with the project configuration
* JDK version compatible with the project's Gradle setup

### Installation
1. Clone the repository:

   ```bash
   git clone https://github.com/DanaTahaa/Spendi.git
   ```

2. Open the project in Android Studio.

3. Allow Gradle to sync and download the required dependencies.

4. Run the application on an Android emulator or a compatible Android device.

## Project Structure
The application source code and Android configuration files are organized within the project, with the main application module located in the `app/` directory.
